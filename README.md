### 👨‍💻 Engineering Profile

I am a Software Engineer focused on architecting resilient backend systems, database schemas, and developer tooling. My work ranges from full-scale distributed web ecosystems and API reverse-engineering to system-level resource monitors and algorithmic state machines.

- 🏗️ **Backend & Microservices**: Designing type-safe, schema-driven REST APIs using Fastify, TypeScript, and Express, with Prisma ORM, PostgreSQL, and Redis caching.
- ⚙️ **Reverse Engineering & Automation**: Developing robust catalog migration engines, session/CSRF state handlers, and event-driven automation bots with concurrency control.
- 🖥️ **Systems & Desktop Applications**: Building native desktop utilities with Python & PyQt6 (process monitors, signal handling, psutil) and JavaFX (transactional desktop suites).
- 📱 **Modern Frontend & Mobile**: Crafting reactive interfaces with React 19, TanStack Router & Query, Chakra UI, and cross-platform apps in Flutter.
